# Limitations & Future Scope

## 5. Limitations

The current project has some limitations:

1. Meter pulses are simulated using software.
2. No physical energy meter hardware is connected.
3. The tariff is an example/configurable value.
4. The system currently works through the Linux terminal.
5. The project does not provide a graphical dashboard.

## 6. Future Improvements

The project can be improved in the future by:

1. Connecting a real energy meter or sensor.
2. Adding a graphical or web dashboard.
3. Storing data in a database.
4. Adding daily and monthly energy reports.
5. Adding configurable tariff settings.
6. Adding remote monitoring through IoT communication.
7. Adding more detailed energy usage alerts.

## 7. Conclusion

The Smart Energy Smart-Meter Pulse Counter & Analytics Agent successfully demonstrates a software-based smart-meter system using C++ and Linux.

The project can detect simulated pulses, calculate energy consumption, store readings, analyze energy usage, estimate cost and generate a simple usage alert.

The project also demonstrates basic Object-Oriented Programming, file handling, Linux development and Git version control.
