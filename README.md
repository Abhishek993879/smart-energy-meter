# Smart Energy Smart-Meter Pulse Counter & Analytics Agent

## Project Overview

The Smart Energy Smart-Meter Pulse Counter & Analytics Agent is a simple C++ and Linux-based software project that simulates a smart electricity meter.

The system counts simulated meter pulses, calculates energy consumption, stores readings in a log file and performs basic energy analytics.

## Features

- Pulse simulation
- Pulse counting
- Energy calculation in Wh and kWh
- Meter reading logging
- Total energy calculation
- Average energy calculation
- Peak energy detection
- Electricity cost estimation
- Usage category
- High-usage alert
- Simple C++ OOP implementation
- Linux-based development
- Git version control

## Technologies Used

- C++
- Ubuntu Linux
- g++
- Git
- Linux Terminal
- Nano
